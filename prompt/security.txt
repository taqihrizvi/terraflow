Create a Terraform child module at modules/security with exactly these files: main.tf, variables.tf, outputs.tf.

Do not add descriptions (except the sensitive flag on the password output), defaults, validation, README, or versions.tf.

  variable "name" { type = string }

- location (string)
- resource_group (string)
- tags (map(string))
